ติดตั้ง SPP Project

SUPERPART • ใช้งานแบบแอปบน Android และ iPhone

สแกนเพื่อเปิดเว็บไซต์ https://plom001001.github.io/PromSPP_Visit/

วิธีเพิ่มแอปลงหน้าจอหลัก

Android · Chrome

  1. เปิดลิงก์ด้วย Chrome
  2. แตะเมนู ⋮ มุมขวาบน
  3. เลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
  4. แตะ “ติดตั้ง” เพื่อยืนยัน

iPhone · Safari

  1. เปิดลิงก์ด้วย Safari
  2. แตะปุ่ม Share ⎙ ด้านล่าง
  3. เลือก “Add to Home Screen”
  4. แตะ “Add” มุมขวาบน
กลับไปหน้าเข้าสู่ระบบ

บน iPhone ต้องเปิดด้วย Safari จึงจะเห็นคำสั่ง Add to Home Screen การติดตั้งไม่เปลี่ยนสิทธิ์การใช้งานและยังต้องเข้าสู่ระบบตามปกติ
